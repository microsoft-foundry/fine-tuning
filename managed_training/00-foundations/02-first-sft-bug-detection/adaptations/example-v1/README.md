# Versioned custom-data example

These small files exist to exercise the offline adaptation workflow. They are
not a quality dataset or a recommendation to submit a paid job.

Copy this directory to a new versioned name, replace both JSONL files with data
you are authorized to use, and follow
[`../../../../ADAPT_YOUR_DATA.md`](../../../../ADAPT_YOUR_DATA.md). Never
overwrite the hash-pinned files under `data/`.
