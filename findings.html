Historical-parity reruns for the two distillation demos

Code Distillation

The earlier bounded run generated 20 rows, accepted 17, and trained on 15 with only two validation rows; both base and fine-tuned students passed the four-case sandbox benchmark.

The demo has now been refactored to restore the historical scale and primary gain methodology: roughly 1,500 accepted training examples, one epoch, learning rate 1.3, batch size one, and the original teacher/judge comparison. Fresh live data is required; preserved labels are not substituted.

Current state: the historical-parity live pipeline is still running. The earlier qualified/non-regression verdict remains provisional until the new job and evaluation reach terminal state.

Agent Traces to SFT

The completed parity rerun used 100 independent conversations with exact 80/10/10 conversation-level splits and zero prompt-hash overlap. It restored the original three epochs, learning rate 1.0, batch size one, first-action evaluator, score-at-least-eight pass threshold, and relative-average gain formula.

The base student scored 5.5 with a 10% pass rate; the fine-tuned student scored 10.0 with a 100% pass rate. This is an original-compatible relative gain of 81.82% and a 90-point pass-rate improvement.

Strict full-trajectory diagnostics also improved from 3.3 to 6.1, with exact trajectory match reaching 30%. The strict score remains below the teacher's 9.1, so complete trajectory quality remains a secondary caution rather than a failure of the original demo outcome.

Cross-demo corrective actions and findings

  • Standardized Entra authentication, terminal file/job polling, explicit timeouts, and project failover without storing credentials.
  • Removed unsupported request shapes and parameters, including invalid automatic batch-size submission and incompatible Responses API message/tool formats.
  • Separated service-side grader model identifiers from callable deployment names in Countdown RFT.
  • Preserved exact live-data lineage: generated or fetched inputs were hashed, split, uploaded, and trained without silently replacing them with snapshots.
  • Moved jobs between regions only when model availability, quota, or training type required it; data bytes remained unchanged during controlled retries.
  • Fixed multimodal preprocessing and output truncation, then tested a single controlled lower-learning-rate video run on identical files and holdout order.
  • Corrected Data Designer authentication, token audience, validation APIs, and Windows-safe execution for Code Distillation.
  • Repaired 367 missing trace call identifiers and removed conversation-level leakage in Agent Traces.
  • Kept service failures explicit. Math RFT and the additional GPT-OSS experiment are reported as blocked rather than represented as successful inference runs.
