# Code-repair training assets

No live training or evaluation evidence is bundled with this tutorial.
Do not fabricate reward curves or treat another model's results as evidence
for MAI-Code-1.1-Flash.

Keep current service CSVs, manifests, and runtime identifiers in this demo's
ignored `outputs/` directory. Any future representative asset must be sanitized
and labeled as a past run, not the reader's result.

Actual results may vary by model version, data, configuration, region availability, and service conditions.
