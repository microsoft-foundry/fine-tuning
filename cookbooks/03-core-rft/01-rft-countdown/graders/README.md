# Countdown graders

- `countdown_python_grader.py` is the canonical deterministic grader used for training and independent exact-answer evaluation.
- `preserved/countdown-model-score-grader.json` and its prompt are byte-identical source artifacts for the model/score variant.
- The preserved solver prompt and response schema define the shared output contract.

`hashes.json` covers both the canonical implementation and all preserved grader inputs.
